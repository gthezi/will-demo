## 本地运行

在本目录执行：

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端输出的本地地址。默认端口为 5173，若被占用，以实际输出为准。

```powershell
npm run build
npm run lint
npm test
```

`build` 执行 TypeScript 检查并输出 `dist/`；`lint` 执行 Oxlint。
`test` 使用 Node 自带测试运行器验证解析、校验与保存规则。测试依赖 Node 对 TypeScript 类型擦除的支持，当前验证环境为 Node 25.8.2。
当前构建仍有单个产物超过 500 kB 的体积提示，后续按业务页面增长情况拆分。

## 主题与导航

- 支持日间、夜间、跟随系统，首次默认夜间。
- 偏好存入 `localStorage` 的 `will-react-theme-v01`，与原型数据隔离。
- 跟随系统会响应运行中的系统外观变化；手动选择不受系统外观影响。
- 存储不可用时仍可切换，偏好仅留在内存；无效存储值回退夜间。
- 顶栏与设置页共用同一主题状态。
- 桌面保留 88px 窄导航栏，小屏收窄至 60px；内容随宽度调整和堆叠。
- 导航切换使用 React 页面状态，尚未引入 URL 路由，刷新后返回首页。

## 助手流程

1. 点击顶栏“AI 助手”，或“添加安排 → AI 整理”，输入文本或选择示例。
2. 点击“生成草案”，或按 Ctrl / Command + Enter。草案生成期间可以关闭抽屉以取消整理。
3. 在摘要中核对标题、日期时间和关联项目；点击带铅笔图标的“编辑”展开表单，修改类别、时长和提醒偏好，也可移除单项。收起后可以直接确认；缺失字段在确认时自动展开并定位错误。
4. 点击“确认添加”，全部草案通过校验后才整批保存。确认结果可跳转到对应日期或项目。

- 当前明确标记为本地模拟，不调用 LLM，不发送任何识别请求。
- 支持有限的中文日期、相对日期、星期、中文时刻及 `HH:mm`；复杂语句的结果需人工核对。
- 没有年份的月日使用当年，并显示提示；未明确识别出的日期 / 时间留空，补全前不能确认。
- 关闭抽屉会保留当前输入或草案；取消草案不写入安排。未确认的草案不持久化，刷新会丢失。
- 草案使用稳定编号；重复确认同一批草案不会重复新增。
- 确认后数据存入预览版键 `will-prototype-schedule-v01`；首次可读取旧 React 数据，后续不覆盖旧键。原 HTML 数据不自动读取。
- 本地存储失败时显示“仅在本次页面中保留”；发现损坏数据时保留原始存储内容，当前会话以内存方式工作。
- 首页提供任务进度、近期截止和全日期检索；日历可查看指定日期；项目按用户的项目分组展示安排，待办勾选会更新进度。

## 首页工作台

- 双栏布局组合任务进度、近期截止、待办清单、月历与所选日期安排、项目概览；小屏依次堆叠。
- 任务进度统计全部待办；近期截止范围在设置中选择 3（默认）、7、14、30 天，包含本地今天及随后 N−1 个自然日，只计未完成且未逾期的待办。截止时刻严格早于当前本地时间即为逾期。
- 近期截止指标与列表使用同一集合；超过 4 项时显示当前项数和总数，可在原卡片内展开全部。逾期单独计数，首页指标和截止卡片均提供展开逾期待办的入口。
- 截止范围独立存入 `will-react-upcoming-range-v01`；无效值回退 3 天。存储不可用时显示警告，设置在当前会话仍然生效；不改安排、项目、主题与名称的存储格式。
- 待办清单展示前 6 项，可前往项目页查看全部。顶栏“快速添加”保留 AI 输入与手动添加菜单；小屏显示加号，随页面正常滚动，不覆盖内容。
- 标题搜索忽略首尾空白和字母大小写；可组合项目、日程 / 待办、完成状态筛选。状态中的未完成 / 已完成仅针对待办。
- 搜索图标展开筛选；任意筛选生效后改为“全部日期”的结果列表，可找到历史事项、远期安排与归档项目内的事项。关闭搜索会清除筛选。
- 区分“还没有安排”、“没有符合筛选条件的安排”和分组为空；项目筛选显示归档标记。
- 搜索与筛选不写入本地存储；条件在当前首页会话中保留，跳页或刷新后重置。编辑弹窗和主题切换不会清除条件。
- 沿用标题编辑、改期和待办完成 / 恢复操作；保存或勾选后立即按当前条件重算视图，首页、日历与项目共享原数据。
- P1 以后本地时钟每秒更新，窗口重新聚焦或页面恢复可见时立即校时；无需刷新即可更新截止状态。
- 空状态和导航栏均可载入示例；设置页提供清空安排，载入与清空均需确认。

## 事项管理

- 首页、日历和项目均提供“添加安排”菜单，可选手动添加或 AI 整理。
- 手动添加默认待办，标题和时间需明确填写；首页默认今天与个人事务，个人事务归档后改用首个进行中项目；日历沿用所选日期，项目沿用当前项目。
- 手动添加保存后保留当前页面，并更新所选日期；日历和首页所选日期安排同步更新。
- 点击任何安排的标题打开编辑弹窗。待办勾选框只切换完成状态，不打开编辑器。
- 日期、时间、类别、项目、时长和提醒与助手草案使用同一套字段和校验；取消、关闭或 Escape 不写入修改。
- 编辑保留事项编号；待办的完成状态也保留。待办转为日程会移除完成状态，日程再转为待办时视为未完成。
- 改期或换项目后，各页面按更新后的数据归类，日历定位到修改后的日期。
- 点击删除后须再次确认；选择“保留事项”不会修改数据。确认后安排、日历计数和项目进度同步更新。
- 保存和删除均复用原有本地持久化；存储不可用时显示本次页面有效的提示。

## 项目管理

- 项目页提供“进行中 / 已归档”两个视图，可新建项目；每个项目的管理菜单可改名和归档。
- 首次使用保留 Will 客户端、课程与学习、个人事务三个初始项目，之后可以自行组织。
- 名称去除首尾空格后为 1–40 字，不允许重名（含已归档项目，拉丁字母忽略大小写）；取消、关闭或 Escape 不保存。
- 项目编号独立于名称；改名会同步更新首页、日历、项目和表单中的项目名称，不修改事项编号、归属和完成状态。
- 归档需要确认，可在已归档视图恢复。归档只改变项目分组，首页和日历仍保留原事项；归档项目中的事项也可编辑或转移到进行中项目。
- 新事项与项目转移只能选择进行中项目；归档项目在选择器中禁用，原属于该归档项目的事项可以保留原归属保存修改。
- 手动添加与 AI 草案均支持自建项目。模拟识别指向已归档初始项目时，优先改用进行中的个人事务，再回退到首个进行中项目。
- 所有项目均可归档；没有进行中项目时手动添加禁用，AI 草案要求先在项目页新建或恢复项目。
- 项目和事项在预览版键 `will-prototype-schedule-v01` 中作为同一份版本 2 数据保存。兼容读取旧 React 数据及版本 1 数据，用户首次明确修改后写入预览版键。
- 项目存储损坏或存在悬空事项归属时显示警告，保留原始存储，仅在本次页面中修改；存储受限时的项目操作也会明确提示。
