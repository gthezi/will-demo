# 原型视觉打磨

日期：2026-11-05

## 设计方向

产品评审认为原型的布局和画面更友好。本轮保留已迁移的 React 交互，恢复原型的卡片、间距和深浅层次，并调整任务进度与助手草案。日程与待办的数据规则保持不变。

改造前界面固定为 `design-review-baseline-2026-11-05`，对应提交 `5982e1d`；本轮版本使用标签 `prototype-visual-refinement-2026-11-05`。

## 页面变化

- 首页的近期截止、待办清单和项目概览恢复独立卡片；月历、日历详情、项目与设置页采用一致的背景、边界和 16px 圆角。
- 项目概览中的条目使用留白和细分隔，避免卡片内继续叠加边框。
- 任务概览保留真实进度，以细圆弧及完成数量展示；明确统计全部待办，取消重复的百分比显示，保留近期截止和逾期数量。
- 近期截止用“今天截止”“还有 2 天”“已逾期”等文字表达紧迫程度，替换没有明确单位的长条。今天尚未截止的事项使用提醒色，已过截止时间才使用逾期色。
- 导航标记、选中背景和快速添加按钮调整轮廓，与原型风格协调。手机上的快速添加收为加号按钮，减少对列表的遮挡。
- 窄屏设置页将主题选项的图标和名称上下排列，适应卡片内宽度。

## 助手变化

草案默认显示标题、日期时间、关联项目和已设置的提醒，点击编辑图标展开完整表单。修改后摘要同步更新，收起表单后可以直接确认。确认按钮保留在抽屉底部。

折叠仅影响展示，字段仍参与校验。确认时如存在缺失或无效字段，对应表单自动展开并定位错误，不写入安排。删除前面的草案时，后面草案的编辑内容和展开状态依照编号保留。

AI 继续使用本地规则模拟；提醒继续只保存偏好，不发送通知。

## 验证

构建、Oxlint 与 44 项领域测试通过。浏览器检查覆盖原有事项和项目流程，以及摘要展开、编辑、收起后确认、缺失字段自动展开、删除草案后保留相邻草案内容。

画面检查覆盖日夜主题、空状态、长标题和项目名，以及 1920、1024、768、390、320px 下的四个页面。截图和结果保存在本机 `release/design-local-checks/`，最后的圆环边界与月历标题检查截图位于 `release/design-final-screens/`；发布后的对应检查保存在 `release/design-online-checks/`。
