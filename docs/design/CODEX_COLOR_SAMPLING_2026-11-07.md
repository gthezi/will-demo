## 取样方法与来源

直接用 `System.Drawing.Bitmap.GetPixel(x, y)` 读取原 PNG 的 RGB 值，并在对应区域统计众数。两张 Codex 截图均为 2559 × 1527，坐标从左上角 `(0, 0)` 起算，没有先缩放图片。

- 浅色：`codex-clipboard-15a16eb6-b9ad-4f24-a9b0-899d191be0c7.png`。
- 深色：`codex-clipboard-f75b73ca-2eb4-4efd-a977-168ecabc8cc7.png`。

截图实测值是最终合成像素，不代表已取得官方设计 Token、原始透明度或材质配置。窗口栏、选中项和细边线存在空间色差，下表是指定坐标的精确读数；文字取正文/侧栏文字区域的高频实色，不取抗锯齿边缘。

| 区域 | 浅色 | 深色 | 取样位置/方式 |
| --- | --- | --- | --- |
| 顶部窗口背景 | `#ECF6F9` | `#1A2225` | `(50, 40)` |
| 左侧会话栏 | `#F8FCFD` | `#191C1D` | `(300, 300)` |
| 选中会话 | `#EBF0F1` | `#2C2E2F` | `(150, 450)` |
| 主工作区 | `#FFFFFF` | `#181818` | `(1000, 200)` |
| 底部输入框 | `#FFFFFF` | `#363636` | `(1000, 1380)` |
| 正文文字 | `#1A1C1F` | `#DFDFDF` | 正文区域高频实色 |
| 侧栏文字 | `#3B3E40` | `#C1C2C2` | 侧栏文字区域高频实色 |
| 发送/停止按钮底色 | `#1A1C1F` | `#DFDFDF` | `(2290, 1435)` |

| 用户消息气泡 | `#F3F3F4` | 未在本张图中取样 | 浅色 `(1500, 920)` |
| 代码块主体 | 未取得完整主体 | `#2A2A2A` | 深色 `(1500, 800)` |

补充证据：

- 输入框 `(1000, 1380, 200, 25)` 区域共 5000 像素，浅色全部为 `#FFFFFF`，深色全部为 `#363636`。
- 选中项 `(140, 440, 40, 35)` 区域中，浅色 `#EBF0F1` 占 75.07%，深色 `#2C2E2F` 占 71.36%；其余为近邻色。
- 浅色代码块仅露出顶部，样本在 `#F2F2F2`、`#F3F3F3` 等颜色间变化，不据此指定完整代码区底色。
- 浅色输入框上缘还取到 `#EFEFEF`，深色上缘取到 `#424242`；这是细边线的显示像素。

最早的另一张设计参考图明确标注：背景 `#191A1C`、二级背景 `#26282C`、选中项 `#313131`、边框/分隔线 `#40434A`。这组色值作为原始参考保留，不能与上面两张 Codex 桌面截图的实测值混称为一套官方配色。

## 本次映射到 Will

以下是应用到 Will 原有组件的设计映射，不意味着 Codex 中所有同类控件都使用这些颜色。

| Will Token/用途 | 浅色 | 深色 |
| --- | --- | --- |
| `bg`：页面底色 | `#FFFFFF` | `#181818` |
| `sidebar`：原窄导航背景 | `#F8FCFD` | `#191C1D` |
| `surface`：原内容卡片 | `#FFFFFF` | `#2A2A2A` |
| `elevated`：输入和浮层背景 | `#FFFFFF` | `#363636` |
| `selected`：导航/日期选中背景 | `#EBF0F1` | `#2C2E2F` |
| `soft`：任务概览/引用背景 | `#F3F3F4` | `#2A2A2A` |
| `soft-subtle`：日历次级背景 | `#F8FCFD` | `#191C1D` |
| `text`：正文 | `#1A1C1F` | `#DFDFDF` |
| `muted`：辅助文字 | `#3B3E40` | `#C1C2C2` |
| `border` / `summary-border`：轮廓 | `#DBE5E7` | `#424242` |
| `divider` / `orbit-border`：细分隔 | `#DBE5E7` | `#2D3437` |

保留原 P1 的蓝色操作色、成功/近期/逾期的状态色及其语义，不把截图中的黑白发送按钮机械套到全部按钮。面板阴影只中和颜色，保留原阴影尺寸。Drawer 沿用原 Ant Design 浮层结构，实际外层背景使用 `elevated`，底部操作区使用 `surface`。Electron 的启动底色改为深色主背景；原生标题栏不改造，不仿造截图的窗口材质。

本次不调整字体、字号、间距、圆角、边框宽度、排版、导航、页面文案、任务模型、持久化键、草案行为或依赖版本。原 P1 尚未包含 W1/W2 功能，不把本次改色描述为对 W1/W2 的功能回退。
