# Will V1 设计系统

2026-11-07。适用样板：首页、AI 工作区、AI Drawer 与草案审阅。项目、日历、设置仅继承基础 Token 和可达性修复，完整视觉统一留待 V2。

## 颜色与主题

颜色唯一来源为 `will-app/src/theme.ts` 的 `palettes`。`applyDocumentTheme` 发布 CSS Variables，`getThemeConfig` 同时配置 Ant Design。保留日间、夜间和跟随系统的原存储键与切换逻辑。

| `--will-bg` | `#f6f3ec` | `#171816` | 页面底色 |
| `--will-surface` | `#fbfaf6` | `#1f211e` | 输入、审阅操作区、Drawer |
| `--will-elevated` | `#ffffff` | `#292c27` | 菜单、选择器等浮层 |

## 排版与尺度

- 仅使用系统字体：`"Segoe UI", "Microsoft YaHei", system-ui, sans-serif`，未下载或打包字体。
- `--will-font-heading` 目前指向同一字体栈，保留后续标题字体的独立配置点。
- 正文 14px、辅助信息 12–13px、模块标题 17–18px、页头 20px；数字启用 `tabular-nums`。不随窗口宽度缩放字号。
- `index.css` 定义 4/8/12/16/24/32px 间距阶梯、4px 控件圆角、8px 面板/浮层圆角。首页模块使用无框布局；重复项优先用清单行。
- 控件常规高度 36px；窄窗口页头图标按钮 34px。长任务、消息和来源原文可换行，不能靠省略号隐藏关键草案。

## 控件与状态

- 页头「快速添加」是主要操作，AI 助手为次要按钮；原入口与导航结构保留。
- 选中导航使用底色、文字和左侧细线。hover 不改变尺寸。所有可聚焦元素有可见的 2px focus outline。
- AntD Button、Tag、Segmented、Input、Select、Modal、Drawer、Progress 使用组件 Token，避免广泛 `!important` 覆盖。
- Mock 用低权重文字和短色线标注；仍明确是本地规则模拟，不能暗示真实模型能力。
- 操作反馈在页头下方的独立文档流区域显示，不覆盖标题或草案操作；错误和持久化警告仍保留在原来的就地提示中。
- 尊重 `prefers-reduced-motion`，不添加额外动画。

## 页面样板

首页保留 W1 数据口径与主要模块。近期截止承担日期提醒，待办清单包含无日期任务；两者有意保留数据交集。用完成数量与线性进度替代圆环，增加未设截止数量；去掉模块浮框和普通待处理标签，保留紧急/进行中/完成状态。

AI 工作区在宽度大于 1150px 时，以剩余窗口高度容纳对话与审阅两列，两列独立滚动。其余宽度采用文档流堆叠。每个批次自己的操作区在其滚动容器底部 sticky，保留最后一项之后的空间；不把多个批次的确认混成一个全局操作。

Drawer 与完整页面沿用同一会话和草案组件。新批次出现后定位审阅标题，不抢键盘焦点；「审阅 N 项草案」和「返回输入」提供明确往返。编辑、暂存和状态更新不会反复触发定位。

批次目标项目作为醒目的整体设置；单一项目的条目不反复展示项目名。混合项目、未选项目或归档项目仍逐条提示。每批表单使用批次 ID 命名，避免字段标签和错误定位跨批次；原验证、来源和确认规则不变。

## 边界

未更改业务模型、AI 存储结构或确认顺序。390px 沿用现有窄导航，隐藏此宽度下无实际作用的展开开关；从宽窗缩小时仍强制紧凑布局，不新增手机底栏。月历的展开样式限定在自己的根元素，避免侧栏同名状态误触发。V2 可在用户确认后将清单语言扩展到项目和日历，W3 可复用字体、颜色、分隔线和控件状态；本轮不新增对应页面。
