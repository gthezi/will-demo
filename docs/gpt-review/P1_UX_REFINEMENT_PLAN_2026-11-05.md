## P1-1｜统一状态语义与视觉语言（先做）

### 问题与定位

当前 `MonthCalendar.css` 将所有任务点与月视图任务条默认染成红色，`ScheduleList.tsx` 以金/红/绿标签表示待办、逾期、完成，首页则用红色专指逾期、黄色指今天截止。跨页面语义不一致。任务类型与紧急程度是两个不同维度，不宜仅靠颜色混合表达。

### 推荐规则（可用主题变量微调，不强制绝对色值）

| 语义 | 建议表现 | 文字/图标 |
|---|---|---|
| 日程（event） | 蓝色系，仅代表类型 | “日程”、日历图标 |
| 普通未完成待办（task） | 中性或低饱和色；**不默认红色** | “待办”、方框 |
| 今天尚未过期的待办 | 警示黄色/橙色，轻量突出 | “今天截止” |
| 已逾期未完成待办 | 红色，仅用于真正逾期 | “逾期”或“已逾期” |
| 已完成待办 | 绿色或淡化/删除线 | “已完成”与选中状态 |

- 颜色与文字、图标同时表达状态，不能仅靠颜色区分。
- 统一首页近期截止、日历点与条、日历当日清单、项目页的显示。注意“某天有待办”可以用普通标记，不代表它逾期；月历上最好不让所有有待办的日期变红。
- 优先复用 `theme.ts` 中现有主题令牌；必要时添加清晰命名的中性待办颜色令牌并同时支持日/夜主题，不要引入大量任意色。
- **一起消除之前审查记录的时间边界差异**：`domain/dashboard.ts` 的 `deadlineView` 按具体时刻判定逾期，旧 `isOverdue` 使用到分钟的字符串比较。请统一调用可靠的同一业务规则；只改 UI/计算 helper 与测试，不改变任务数据模型。
- 检查截止当天尚未过期、截止当分钟、超过一分钟、完成/恢复、仅日程、跨天/跨月、不同主题等情况。

**验收**：同一事项在首页、月历、项目/日程列表的类别与状态一致；普通未到期待办不再因为“是待办”而显示逾期红；今天和逾期能区分；无功能回归。

## P1-2｜首页信息重点：让“现在该做什么”更明显

### 设计方向

现有双栏卡片、右侧月历和项目概览已被认可，保留其整体位置和视觉语言。当前顶部大面积“任务进度”圆环显示全部待办的完成比例，信息真实，但对用户此刻要做什么的指向较弱。我们希望让今日/近期任务更容易看到，同时保留进度作为辅助信息。

### 实施边界

- 优先做**保守的局部调整**：降低总进度圆环的视觉强度或占用面积；增强“今天截止/近期截止/逾期入口”的可读性和到达速度。不要为了优化一个卡片而把首页全部重新排列。
- 保留原有完成数、未完成数、用户自定义 3/7/14/30 天范围、逾期独立列表、项目进度与日历联动；**不要把所有任务完成率当作今天的完成率**。
- 保持“今天还没有截止任务”“全部任务已完成”“仅逾期”“超过四项可展开”等状态清楚。没有数据时不显示伪造的数字。
- 如果首页新增加简短的今日提示，其数字只能从当前数据实时计算，不要新增一份独立、易失同步的状态。
- 先给出改前/改后同数据、同窗口尺寸的 1440px 日间和夜间对照。若没有明显可读性提升、反而使首页拥挤，应退回更保守版。无需开发多套长期并存的主题/首页选项。

**验收**：初次打开首页，今日及近期需要处理的事项可以很快识别；任务进度仍可读但不抢占主要注意；各屏幕尺寸没有明显布局回退。

## P1-3｜搜索/筛选位置与结果语义（完成前两项后再做）

### 当前行为

`HomePage.tsx` 的搜索按钮位于“待办清单”标题，点开后却在整张首页顶部显示 `will-dashboard-filters`；过滤结果仅替换“待办清单”卡片内容。搜索可涵盖**全部日期的日程与待办**，因此实际上已经不只是“筛选待办”。

### 推荐交互

- 让过滤操作与结果**视觉相邻**，优先在待办/安排卡片内展开搜索与筛选，或采用不覆盖主要内容的紧邻区域。既有 2 栏布局不应被大范围推挤。
- 无筛选时，卡片继续叫“待办清单”，默认展示规则维持。进入搜索模式后明确显示“搜索全部安排”（含日程与待办、跨日期），并显示命中总数；能方便返回未筛选列表。
- 搜索字段至少仍支持标题文本、所属项目、日程/待办类型、待办完成状态。现有“清除筛选”继续可用。若用户选择“日程”类型，不能默默把待办的“未完成”状态应用在日程上造成难以解释的空结果；可禁用/重置该状态筛选并提供明确提示。
- 用户关闭搜索后应明确回到默认列表，不能出现“看不到筛选条件，但仍被过滤”的隐性状态。
- 搜索没有结果、长标题、归档项目、键盘操作、清除、切换页面再返回、320px 窄屏均要检查。
- 不新增复杂全局搜索路由、后端搜索，也不重新定义数据搜索范围；只理顺现有局部交互。

**验收**：用户看到搜索面板就知道结果会出现在哪里；结果标题和数量不再将日程误称待办；展开/折叠/清除后状态可预测。
