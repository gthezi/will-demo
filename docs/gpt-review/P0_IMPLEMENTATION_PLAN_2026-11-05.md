## P0-1｜“近期截止”范围由用户选择，统计与列表口径统一

### 背景与决策

当前首页的“近期截止”数字采用**今天至三天后**的日期范围，实际涉及四个日历日期；下面同名列表却简单取排序后前四条未完成待办，可能显示很久以后的任务。二者含义不一致。

用户决定：不同人对“近期”的理解不同，应在 **设置页**允许自行选择。不要仅把数值固定成三天。

### 交互方案

1. 在“个人设置”新增“近期截止范围”一项，使用简洁单选/分段选项：**3 天（默认）、7 天、14 天、30 天**。附近说明“包含今天；逾期事项单独统计”。
2. 将 `N 天`定义为用户本地时区的**今天及随后 N−1 个自然日**。例如 11 月 5 日选择 3 天，覆盖 11 月 5、6、7 日。不要一处按自然日、一处按滚动 N×24 小时计算。
3. “近期截止”只统计**尚未完成且未逾期**的待办，范围由选择决定；逾期的定义为截止日期+时间严格早于当前本地时间。已逾期任务应仍可明显看到或通过明确入口访问，不因范围缩短而消失。
4. 首页指标和“近期截止”列表使用**同一过滤结果集合**。列表最多可以显示最近截止的 4 项，但必须清楚标注“显示前 4 项 / 共 X 项”，并提供查看全部的有效入口；列表为空时提供适当的空状态。
5. 日期范围选择应即刻更新首页，刷新后保留。存储不可用时当前会话仍可使用，并按现有提示方式处理；无效存储值安全回退默认 3 天。
6. 建议首页采用“未来 3 天截止”这类明确称呼，设置改变后同步更新；避免仅写“近期截止”而不说明范围。视空间可保留栏目标题，但附近须显示范围。

### 边界用例与验收

- 当前日期 11/5、选择 3 天：11/5、11/6、11/7 的未过期任务计入；11/8 不计入。修改为 7 天则 11/8 计入。
- 今天上午 9:00 已到期、现在下午 14:00 的未完成待办：统计为逾期；不应同时计入“未来 N 天”。
- 同日 23:00 尚未到期：仍计入今天；完成后两个统计及列表均更新。
- 无待办、全完成、仅有日程、仅有逾期、未来任务超过 4 项、跨月 / 跨年：显示和数量正确。
- 设置后跳页 / 刷新不丢失；不改变用户已有的任务、项目、日历、主题设置。
- 检查更改不会影响日历与项目页的现有任务完成 / 恢复逻辑。

## P0-2｜AI 草案编辑入口更容易发现

### 背景

当前草案默认折叠为摘要、按需展开详细表单，这个方向已经认可，应继续保留。问题是编辑入口只有卡片右上角较小的铅笔图标，初次使用时不容易发现。

### 交互方案

1. 每条草案在摘要态提供**带“编辑”文字的明确操作**，或让摘要主体具有显而易见且键盘可操作的展开入口；不要只依赖 hover 提示。
2. 保留卡片内类别、标题、日期时间、关联项目等可供核对的信息，以及“移除此项”操作。编辑入口与删除入口要有足够间距，避免误点。
3. 展开 / 收起详细字段后，摘要应同步显示用户已改动的值。确认仍必须校验完整草案；字段无效时自动展开错误项并定位；关闭再打开不丢失当前草案。
4. 不改变原有整批确认、取消草案、重复确认防重，以及真实服务端尚未连接的状态。
5. PC 与 390px/320px 窄屏、浅色/深色主题下，操作都应该可见、可点击、键盘可聚焦。

可能涉及文件：`src/components/AssistantDrawer.tsx`、`src/components/AssistantDrawer.css`、既有测试。

## P0-3｜快速添加入口不遮挡内容

### 背景

在 1440px 首页的项目概览、390px 首页的待办区，固定在右下角的快速添加按钮会盖住内容。保留明显的新增入口，但要让用户可以完整阅读和点击底层项目与任务。

### 交互方案

1. **优先考虑 PC 端**把“快速添加”移到顶栏或内容工具区，使其参与正常布局；如果保留悬浮按钮，必须预留内容避让与足够的滚动区域，不能仅在某张截图上巧合地不遮挡。
2. 窄屏端可以保留精简加号，但所有页面在不同滚动位置的末项、操作按钮都必须可见且可触达；尊重安全区域，避免挡住待办勾选框、项目菜单和日期操作。
3. 原有“AI 整理 / 手动添加”的菜单行为必须保留，已有“AI 助手”入口不受影响。
4. 不能因移位导致键盘可访问性、弹出菜单位置、点击区域及双主题样式退化。

### 验收视口

重点检查 1440、1024、768、390、320px 宽度，首页 / 日历 / 项目页至少各看初始位置、滚动到中段、滚动到底部。尝试在最靠边的事项上点击编辑和勾选，确保无遮挡和误触。原有无横向溢出的表现必须保留。

可能涉及：`src/components/WillShell.tsx`、`src/App.css`、页面/窄屏样式。
